# MK37 Kids — piano game for a 4-year-old, iPad

What it is: a web app (PWA) that teaches a child to play her real Medeli MK37 organ (37 keys, colour stickers on white keys).
The whole iPad screen looks like the MK37 panel; the game runs in a "magic window"; 37 mini keys at the bottom.

## Live
- Site: https://roy7534.github.io/mk37-kids/ (GitHub Pages, branch `gh-pages` = contents of `web/`)
- Repo: github.com/roy7534/mk37-kids (public — needed for free Pages)
- Deploy: commit on `main`, then `git subtree split --prefix web -b gh-pages && git push -f origin gh-pages`. Bump `CACHE` in `web/sw.js` on every deploy.

## Structure
- `web/index.html`, `web/css/style.css` — UI (Fredoka font, claymorphism cards inside the organ body)
- `web/js/app.js` — screens, MK37 panel logic, games (find colour / echo / song necklace), rewards, editor, parent area
- `web/js/art.js` — all art as SVG (Noti eighth-note mascot + accessories, 30 sticker creatures, icons, functional MK37 panel + 7-seg LED)
- `web/js/audio.js` — Web Audio synth (200 sounds in MK37 categories, 120 styles, SFX), `playBuffer` for voice clips
- `web/js/voice.js` — voice: parent in-app recording (IndexedDB) > `voice/mom/*.m4a` > `voice/{f,m}/*.mp3` (Hila neural) > device TTS
- `web/js/input.js` — MIDI (Web MIDI + native bridge `window.nativeMidi`) and mic pitch detection (YIN); mic ignored while app makes sound
- `web/js/songs.js` — 12 public-domain songs; `phrases.js` generated by `tools/make_voice.py`
- `ios/NotiPiano/*.swift` — optional native WKWebView shell with CoreMIDI for USB-C cable (not built: no Xcode on this Mac)

## Decisions
- Games accept only the real organ (mic or MIDI). Screen keys count only in parent "test mode"; in free play they are an instrument.
- Parent area: long-press (1.8 s) the power button ⏻ on the panel.
- Note matching is by pitch class (octave-free) unless "strict octave" + MIDI.
- Mom's voice (2026-11-23): one long recording split by silence into 39 clips (order = keys in phrases.js), sticker line replaced by a separate corrected take. Default voice pack = mom; parent can switch to Hila.
- No emojis — all art is original SVG.
